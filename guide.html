📌 시작하기

로그인 및 첫 화면

Firebase 계정으로 로그인하면 내 이벤트만 안전하게 관리할 수 있습니다.

1
회원가입 — 이메일과 비밀번호(6자 이상)를 입력하고 가입합니다.
2
로그인 — 이후 방문 시 이메일·비밀번호로 로그인하면 내 이벤트 목록이 나타납니다.
3
헤더 우측 로그아웃 버튼으로 언제든지 안전하게 종료할 수 있습니다.
ℹ️ Firebase 미설정 상태에서도 앱을 사용할 수 있습니다. 이 경우 데이터는 브라우저 로컬 저장소에만 보관되며 다른 기기에서는 볼 수 없습니다.
📅 이벤트

이벤트 만들기 · 관리

하나의 이벤트 안에 참가자, 찬조, 운영진, 조편성 데이터가 모두 묶입니다.

＋

새 이벤트 만들기

이벤트 목록 화면에서 ＋ 새 이벤트 만들기 버튼을 누릅니다. 제목은 필수, 나머지는 나중에 수정 가능합니다.

✏️

수정

이벤트 카드의 ✏️ 수정 버튼 또는 기본정보 탭의 수정 버튼으로 언제든지 내용을 변경할 수 있습니다.

📋

복사

기존 이벤트를 그대로 복제합니다. 정기 대회처럼 같은 형식을 반복할 때 유용합니다.

🗑

삭제

이벤트와 함께 참가자·찬조·운영진 데이터가 모두 삭제됩니다. 되돌릴 수 없으니 주의하세요.

이벤트 입력 항목

항목설명
이벤트 제목 필수목록과 헤더에 표시되는 이름
이벤트 내용행사 소개 문구
이벤트 목적친목, 실력 향상 등 목적
일자YYYY-MM-DD 형식으로 자동 입력
장소행사 장소명
주최/주관클럽명 또는 단체명
안내사항참가자에게 전달할 공지 (신청 페이지에도 표시)
참석 신청 옵션운동 / 운동+회식 / 회식 중 원하는 항목 체크. 체크된 항목만 공개 신청 페이지에 표시됩니다.
📋 기본정보 탭

기본 정보 확인

이벤트 상세 화면의 첫 번째 탭으로, 이벤트 요약 정보와 참석 신청 링크를 확인할 수 있습니다.

📊

현황 배지

참가자 · 찬조자 · 운영진 현재 인원이 한눈에 표시됩니다.

🔗

참석 신청 링크

참석 신청 옵션을 하나 이상 체크하면 공개 신청 링크가 생성됩니다. 복사 버튼으로 링크를 복사해 카카오톡 등으로 공유하세요.

👥 참가자 탭

참가자 관리

3가지 방법으로 참가자를 등록할 수 있으며, 중복 감지 기능이 자동으로 작동합니다.

＋

직접 추가

한 명씩 이름·급수·성별·나이·경력·소속·연락처를 입력합니다.

📋

텍스트 붙여넣기

엑셀에서 복사한 내용을 그대로 붙여넣으면 한 번에 여러 명을 등록합니다.
컬럼 순서: 이름, 급수, 나이, 경력, 성별, 소속, 연락처, 비고
구분자는 탭·쉼표·파이프(|) 모두 지원합니다.

📁

파일 업로드

CSV, TXT, Excel(xlsx/xls) 파일을 직접 업로드해 일괄 등록합니다.

⚠️

중복 감지 자동

같은 이름 또는 동일한 연락처가 이미 등록되어 있으면 경고창이 뜹니다. 계속 추가할지 취소할지 선택할 수 있습니다.

⬇

CSV 내보내기

현재 참가자 명단 전체를 CSV 파일로 저장합니다.

💡 참석 구분(운동 / 운동+회식 / 회식)이 설정된 경우 참가자 목록이 그룹별로 구분되어 표시됩니다.
📊 참가자 통계

참가자 구성 통계

참가자 탭 상단에 자동으로 표시되는 시각화 차트입니다.

⚥

성별 분포

남 / 여 / 미설정 비율을 막대 차트로 표시합니다.

🏅

급수 분포

S·A·B·C·D·초보 순으로 각 급수별 인원 비율을 표시합니다.

🏃

참석 구분 분포

운동·운동+회식·회식 등 참석 구분별 인원을 표시합니다. 참석 구분이 없으면 자동으로 숨겨집니다.

💡 통계 섹션 제목을 클릭하면 접기·펼치기가 가능합니다.
🤝 찬조 탭

찬조 관리

찬조자와 찬조 물품을 함께 관리합니다.

🤝

찬조자 등록

찬조자명·연락처·소속·찬조 구분(물품/현금/상품권/식품/기타)·메모를 입력합니다.

🎁

찬조 물품 등록

찬조자 등록 시 물품을 함께 입력하거나, 찬조 물품 목록에서 별도로 추가할 수 있습니다. 물품명·수량·금액·사용처를 기록합니다.

🔍

이름·소속 검색

찬조자 목록 상단의 검색창으로 빠르게 찾을 수 있습니다.

🛠 운영진 탭

운영진 관리

행사를 함께 진행하는 운영진을 역할별로 등록합니다.

역할설명
총괄행사 전체 진행 책임자
진행행사 당일 진행 담당
경기 운영경기 일정·심판 관리
접수참가자 현장 접수 담당
회계참가비·찬조금 수납 담당
촬영사진·영상 기록
안내참가자 안내 및 유도
기타위 항목에 없는 역할
🏟 조편성 탭

조편성

참가자를 조로 나누어 경기 일정을 자동 생성합니다.

1
조 수 · 팀 수 설정 — 몇 개의 조로 나눌지, 각 조는 몇 팀으로 구성할지 입력합니다.
2
자동 배정 — 급수·성별을 고려해 균형 있게 자동 배정합니다.
3
수동 조정 — PC에서는 드래그 앤 드롭, 모바일에서는 길게 눌러 조 이동 메뉴로 조원을 옮깁니다.
4
경기 일정 확인 — 각 조의 라운드별 대진표가 자동으로 생성됩니다.
💡 밸런스 바로 각 조의 급수 균형 상태를 한눈에 확인할 수 있습니다.
🌐 미리보기 탭

미리보기 · 내보내기

참가자에게 공유할 이벤트 결과물을 다양한 형태로 내보냅니다.

👁

공개 미리보기

참가자·찬조자·운영진·조편성 등 표시할 항목을 체크박스로 선택하면 공개 페이지 형태의 미리보기가 실시간 업데이트됩니다.

⬇

HTML 다운로드

미리보기 내용을 독립적인 HTML 파일로 저장합니다. 오프라인에서도 열 수 있습니다.

📋

텍스트 복사

참가자 명단을 텍스트로 복사해 카카오톡 등 메신저에 바로 붙여넣을 수 있습니다.

🖼

이미지 저장

미리보기 화면을 PNG 이미지로 저장합니다. 단체 카톡방에 공유하기 편합니다.

📝 참석 신청

공개 참석 신청 페이지

로그인 없이 누구나 접근할 수 있는 참가 신청 전용 페이지입니다.

1
기본정보 탭에서 🔗 링크 복사로 신청 링크를 가져옵니다.
2
링크를 카카오톡·문자로 참가자에게 공유합니다.
3
참가자가 이름·성별·급수·나이·경력·연락처·참석 구분을 선택해 신청합니다.
4
신청 내역이 즉시 참가자 탭에 반영됩니다.

🔍 신청 확인·수정

1
신청 페이지에서 🔍 신청 확인·수정 탭을 누릅니다.
2
신청 시 입력한 이름과 연락처를 입력하고 조회합니다.
3
✏️ 수정으로 정보를 변경하거나, 🗑 신청 취소로 신청을 철회할 수 있습니다.
💡 연락처를 입력하지 않고 신청하면 이름만으로 조회되므로 동명이인이 있을 경우 정확한 구분이 어렵습니다. 연락처 입력을 권장하세요.
✅ 신청 페이지는 Firebase 없이도 동작합니다. Firebase 설정 시에는 실시간으로 데이터가 저장됩니다.
💾 이벤트 템플릿

이벤트 템플릿

자주 쓰는 이벤트 설정을 저장해두고 새 이벤트 생성 시 바로 불러올 수 있습니다.

💾

템플릿 저장

이벤트 생성·수정 모달에서 내용을 입력한 뒤 💾 저장 버튼을 누르고 템플릿 이름을 지정합니다. 주최·안내사항·참석 옵션이 저장됩니다.

📂

템플릿 불러오기

이벤트 모달에서 드롭다운으로 저장된 템플릿을 선택한 뒤 불러오기를 누르면 해당 설정이 자동으로 채워집니다.

🗑

템플릿 삭제

드롭다운에서 템플릿을 선택하면 나타나는 삭제 버튼으로 제거합니다.

ℹ️ 템플릿은 브라우저 로컬 저장소에 보관됩니다. 다른 기기나 브라우저에서는 공유되지 않습니다.
